# Anki Decks & Coding Exercises for Learning

A comprehensive collection of Anki flashcards and companion Jupyter notebooks covering various topics in Software Engineering, Data Science, Machine Learning, and Cloud Computing. These resources are designed to facilitate effective learning through [spaced repetition](https://en.wikipedia.org/wiki/Spaced_repetition).

## 🗂️ Available Anki Decks (.apkg)

The following decks are included in this repository, categorized by subject:

### Cloud & DevOps
- **Google Cloud Platform (GCP)**
  - `Coursera-GCP-ML-Specialization-Course1.apkg`: Machine Learning on GCP.
  - `Coursera-Migrating_to_GCP.apkg`: Strategies and tools for migrating to Google Cloud.
- **Infrastructure**
  - `PP__Kubernetes.apkg`: Orchestration and container management.

### Data Science & Machine Learning
- `Data_Mining_PP.apkg`: Core concepts and algorithms in data mining.
- `Hands On ML book - Geron.apkg`: Based on "Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow" by Aurélien Géron.
- `PP__DL Specialization - Coursera.apkg`: Deep Learning concepts from the Coursera specialization.

### Python & Data Structures
- `PP__Python.apkg` & `Python-PP.apkg`: General Python programming syntax and features.
- `PP-DS-Algos-Python.apkg` & `PP__DS-Algos-Python.apkg`: Data structures and algorithms implemented or explained in Python.

### Software Development & Tooling
- `Git Syntax.apkg`: Essential Git commands and workflows.
- `PP-Web-Dev.apkg`: Web development fundamentals.

### Research & Methodology
- `PP-Research-Methodology.apkg`: Methods and processes for scientific research.
- `Research.apkg` & `Research__Process Mining.apkg`: General research topics and Process Mining specifics.

## 🚀 How to Use

### 1. Install Anki
If you haven't already, download and install [Anki](https://apps.ankiweb.net/). It is available for Windows, macOS, Linux, iOS, and Android.

### 2. Import the Decks
1. Clone this repository or download the specific `.apkg` files you are interested in.
2. Open Anki.
3. Go to **File > Import** (or press `Ctrl+I`).
4. Select the `.apkg` file(s) from your local machine.

### 3. Start Studying
The decks will now appear in your Anki dashboard. We recommend studying daily to get the most benefit from the spaced repetition algorithm.
